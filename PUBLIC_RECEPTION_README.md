# Общественный прием - Документация

## Обзор
Система общественного приема позволяет пользователям оставлять обращения через сайт университета, которые затем обрабатываются администраторами через панель Filament.

## Созданные компоненты

### 1. База данных
- **Миграция**: `database/migrations/2026_02_12_085410_create_public_receptions_table.php`
- **Таблица**: `public_receptions`
- **Поля**:
  - `id` - ID обращения
  - `name` - Имя заявителя
  - `email` - Email заявителя
  - `phone` - Телефон (необязательно)
  - `message` - Текст обращения
  - `response` - Ответ администрации (необязательно)
  - `is_processed` - Флаг обработки (по умолчанию false)
  - `is_published` - Флаг публикации (по умолчанию false)
  - `created_at`, `updated_at` - Временные метки

### 2. Модель
- **Файл**: `app/Models/PublicReception.php`
- **Функционал**: 
  - Заполняемые поля (fillable)
  - Автоматическое приведение типов (casts)
  - Форматирование даты `getFormattedDate()`

### 3. Административная панель (Filament)
- **Основной ресурс**: `app/Filament/Resources/PublicReceptionResource.php`
- **Pages**:
  - `ListPublicReceptions.php` - Список обращений
  - `EditPublicReception.php` - Редактирование обращения
  - `CreatePublicReception.php` - Создание обращения (опционально)
- **Функционал**:
  - Просмотр всех обращений
  - Фильтрация по статусу обработки и публикации
  - Добавление ответов на обращения
  - Публикация обработанных обращений
  - Счетчик необработанных обращений в навигации
  - Массовые действия (удаление, отметка как обработанные)

### 4. Контроллер фронтенда
- **Файл**: `app/Http/Controllers/PublicReceptionController.php`
- **Методы**:
  - `index()` - Отображение страницы с формой и опубликованными обращениями
  - `store()` - Обработка отправки формы с валидацией и защитой reCAPTCHA

### 5. Представление
- **Файл**: `resources/views/public-reception/index.blade.php`
- **Функционал**:
  - Адаптивная форма для отправки обращений (мобильная и десктоп версии)
  - Отображение опубликованных обращений с ответами
  - Пагинация обращений
  - Информационный блок
  - Breadcrumbs навигация
  - Обработка ошибок валидации
  - Сообщения об успешной отправке

### 6. Маршруты
- **GET** `/{locale}/public-reception` - Страница общественного приема
- **POST** `/public-reception` - Отправка обращения
- **GET** `/admin/public-receptions` - Список обращений в админке
- **GET** `/admin/public-receptions/{record}/edit` - Редактирование обращения

### 7. Переводы
Добавлены переводы для всех языковых версий сайта:
- **Русский** - ключи в JSON файлах
- **Казахский** - `resources/lang/kk.json`
- **Английский** - `resources/lang/en.json`
- **Китайский** - `resources/lang/cn.json`

## Доступ к функционалу

### Для пользователей сайта
1. Перейти на страницу: `https://ваш-домен.kz/{locale}/public-reception`
2. Заполнить форму обращения (имя, email, телефон (необязательно), текст обращения)
3. Пройти проверку reCAPTCHA
4. Отправить обращение
5. Просмотреть опубликованные обращения и ответы на них

### Для администраторов
1. Войти в админ-панель Filament: `https://ваш-домен.kz/admin`
2. В навигации найти раздел "Обращения" → "Общественный прием"
3. Увидеть счетчик необработанных обращений
4. Просмотреть детали обращения, добавить ответ
5. Отметить как "Обработано"
6. При необходимости опубликовать на сайте (только обработанные обращения)

## Навигационная группа
- **Группа**: Обращения
- **Иконка**: heroicon-o-envelope
- **Бейдж**: Показывает количество необработанных обращений

## Безопасность
- Валидация всех входных данных
- Защита от спама через reCAPTCHA
- CSRF-токены для защиты форм
- Ограничение размера сообщения (2000 символов)

## Дополнительные настройки

### Добавление ссылки в меню сайта
Чтобы добавить ссылку на страницу общественного приема в навигационное меню сайта, необходимо:
1. Добавить пункт меню в административной панели
2. Или добавить статическую ссылку в файл шаблона навигации

### Уведомления
При необходимости можно добавить email-уведомления при получении новых обращений, создав:
- Event/Listener для модели PublicReception
- Notification класс для отправки email администраторам

## Примечания
- Все обращения по умолчанию не опубликованы и требуют обработки администратором
- Только обращения со статусом "обработано" и "опубликовано" отображаются на сайте
- Форма использует те же стили и компоненты, что и страница "Блог ректора" для единообразия дизайна
